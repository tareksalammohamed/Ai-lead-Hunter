# Campaigns + Lead Profile AI Modern v3.3

Implemented additive React UI components:
- `CampaignsAIWorkspace.tsx`: modern campaign cards, search, status filtering, metrics, run actions, empty state.
- `LeadAIProfile.tsx`: AI lead profile hero, score, intent/status/source, summary, contact panel, recommended next step.
- `campaign-profile-v3.css`: responsive styling for Web and Capacitor/mobile.

These components preserve the existing Supabase contracts and can be wired into the existing pages via their callback props.
